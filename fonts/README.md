# Fonts

Darker Grotesque (SIL Open Font License 1.1), self-hosted via woff2 files from
the Fontsource distribution (`@fontsource/darker-grotesque` 5.2.5, latin
subset). Weights 400, 600, 700; the family has no italic cut, so browsers
synthesize oblique for italics.

Referenced by the `@font-face` rules in `styles.css`. The OFL license text is
in `LICENSE`.
